Bilkul. JavaScript me Event Listener bahut important concept hai, especially jab hum webpage ko interactive banate hain. Sabse basic se samjhte hain. 1. Event kya hota hai? Event = user ya browser ke dwara hone wali koi activity. Jaise: button par click karna mouse le jana keyboard se key press karna input box me kuch type karna form submit karna page load hona Example: User ne button ko click kiya. Ye click ek event hai. 2. Event Listener kya hota hai? Event Listener JavaScript ko bolta hai: "Is element par nazar rakho. Jab ye event ho, tab ye kaam karna." Example: button.addEventListener("click", function () { console.log("Button clicked"); }); Meaning: button ↓ click hone ka wait karo ↓ click hua? ↓ function chalao ↓ "Button clicked" 3. Basic Syntax element.addEventListener("event", function); Isme 3 important cheezein hain: element.addEventListener("click", function); element Kis HTML element par event detect karna hai. Example: button "click" Kaunsa event detect karna hai. function Event hone ke baad kya kaam karna hai. 4. Complete Example HTML: JavaScript: let button = document.querySelector("#btn"); button.addEventListener("click", function () { console.log("Button clicked"); }); Ab line-by-line samjho. JavaScript: let button = document.querySelector("#btn"); let heading = document.querySelector("#heading"); button.addEventListener("click", function () { heading.innerText = "Welcome"; }); Initially webpage: Hello [Click Me] Button click: Welcome [Click Me] Kyun? Because: heading.innerText = "Welcome"; heading ka text change kar raha hai. 7. Function alag bhi bana sakte hain Humne abhi likha: button.addEventListener("click", function () { console.log("Clicked"); }); Ye anonymous function hai. Lekin function pehle bhi bana sakte hain: function showMessage() { console.log("Clicked"); } button.addEventListener("click", showMessage); Meaning: click hua ↓ showMessage function call hua Important: button.addEventListener("click", showMessage); Usually yahan: showMessage likhte hain. Ye nahi: showMessage() Kyunki showMessage() likhne par function turant execute ho sakta hai. 8. Common Events JavaScript me bahut saare events hote hain. click button.addEventListener("click", function () { console.log("clicked"); }); Button click hone par. dblclick Double click: button.addEventListener("dblclick", function () { console.log("double clicked"); }); mouseover Mouse element ke upar aaye: button.addEventListener("mouseover", function () { console.log("Mouse aa gaya"); }); mouseout Mouse element se bahar jaye: button.addEventListener("mouseout", function () { console.log("Mouse bahar gaya"); }); keydown Keyboard ki key press hone par: document.addEventListener("keydown", function () { console.log("Key pressed"); }); input Input box me user kuch type kare: let input = document.querySelector("#name"); input.addEventListener("input", function () { console.log("User typing..."); }); change Input/select ki value change hone par: input.addEventListener("change", function () { console.log("Value changed"); }); submit Form submit hone par: form.addEventListener("submit", function () { console.log("Form submitted"); }); 9. Event Object kya hota hai? Event Listener function ko JavaScript automatically event ke baare me information deta hai. Example: button.addEventListener("click", function (event) { console.log(event); }); Yahan: event ek object hai. Isme information hoti hai: kis element par click hua mouse kaha tha kaunsi key press hui event ka type kya tha Commonly event ko short me: e likhte hain. button.addEventListener("click", function (e) { console.log(e); }); 10. e.target Bahut important hai. button.addEventListener("click", function (e) { console.log(e.target); }); e.target batata hai: actual me kis element par event hua. Example: Click karne par: console.log(e.target); roughly ye element milega: 11. Button ka text change using e.target button.addEventListener("click", function (e) { e.target.innerText = "Clicked"; }); Pehle: [Click Me] Click ke baad: [Clicked] 12. Input value kaise lete hain? HTML: JavaScript: let input = document.querySelector("#name"); input.addEventListener("input", function (e) { console.log(e.target.value); }); User type kare: Imam Console: I Im Ima Imam Because har input change par event run ho raha hai. 13. onclick vs addEventListener Aapne shayad HTML me dekha hoga: Aur: function hello() { console.log("Hello"); } Ye bhi event handling hai. Lekin modern JavaScript me generally preferred hai: button.addEventListener("click", hello); Kyuki HTML aur JavaScript separate rehte hain. HTML: JavaScript: let button = document.querySelector("#btn"); button.addEventListener("click", function () { console.log("Hello"); }); Ye zyada clean approach hai. 14. Ek element par multiple Event Listeners Ye addEventListener() ka important advantage hai. button.addEventListener("click", function () { console.log("First function"); }); button.addEventListener("click", function () { console.log("Second function"); }); Button click karoge: First function Second function Dono execute honge. 15. Event Listener remove bhi kar sakte hain Syntax: element.removeEventListener("click", functionName); Example: function hello() { console.log("Hello"); } button.addEventListener("click", hello); Remove: button.removeEventListener("click", hello); Ab click karne par hello execute nahi hoga. 16. Form me preventDefault() Bahut common concept hai. Normally form submit hone par page reload ho sakta hai. Example: form.addEventListener("submit", function (e) { e.preventDefault(); console.log("Form submitted"); }); preventDefault() meaning: browser ka default behaviour rok do. Form case me: submit ↓ normally page reload ↓ preventDefault() ↓ page reload stop 17. Complete practical example Event Listener
